# WoW Companion Dungeon Beta

Windows beta of the offline dungeon reference companion. Downloads are public and do not require a GitHub account.

## Scope

- 34 dungeon views with quest chains and source-backed map references.
- Saved tooltips for 527 reward items.
- Local bug-report ZIP files with an optional beta-window screenshot.
- Configurable global Windows shortcut (default Ctrl+Alt+W).

This beta does not use a live quest log or plan routes. Catalog locations do not confirm a current quest offer.

## Installation

Download the versioned Setup executable from Releases and run it. Installation applies to the current Windows user. A separate Python installation, Node and a WoW folder are not required.

## Reporting a bug

Use **Report a bug** in the app. Describe what happened and what you expected, optionally include the beta-window screenshot, review the diagnostics and save the ZIP locally. Issues and attachments in this repository are public. Review and remove personal information before attaching a report ZIP.

## Current validation

Version 0.1.1 passed installation, packaged UI/map/item-tooltip checks, screenshot and report-ZIP creation, and uninstallation on the development PC. A clean second-device test is still pending. Behavior over exclusive-fullscreen WoW has not been separately verified.

## Distribution status

Early technical test build. The complete bundled-source, artwork and license review remains open. The installer contains supplied third-party notices and an inventory of unresolved source questions. Public availability does not constitute a completed source or license review.
